Reference Notes

What is a CSR?

A Certificate Signing Request contains a public key and identity details, and is signed using the associated private key. A CA evaluates the request before issuing a certificate.

What is a SAN?

The Subject Alternative Name extension specifies DNS names and/or IP addresses for which a certificate is valid. Modern TLS hostname validation relies on SAN entries.

What does OpenSSL verify check?

The verify operation checks certificate trust and signatures against a supplied trust anchor. Hostname validation requires additional checks, such as -verify_hostname portal.example.com.
